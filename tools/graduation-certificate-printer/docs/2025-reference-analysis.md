## 檔案角色

每個獎項資料夾通常包含三種檔案：

- 套印資料檔：Word `.doc` 或 `.docx`，檔名常含「套印資料」、「資料檔」、「合併資料」。
- 獎狀格式檔：Word `.doc` 或 `.docx`，檔名常含「格式」、「範本」、「獎狀」。
- 合併輸出檔：個別學生或合併成果 `.docx`。

部分獎項另有 `word 邊框.jpg` 作為獎狀邊框素材，例如教育基金會、尊親基金會、羅東中區扶輪社。

## 版面與文案規則

解析 `.docx` 後看到的共同特徵：

- Word 頁面尺寸為 A4 直式。
- 許多正式獎狀範本不是橫式，而是直式 A4。
- 部分外部獎項沒有「獎狀」大標題，只印姓名、得獎原因、獎項名稱與日期。
- 多數文案使用 `«姓名»`、`«班級»` 這類 Word 合併列印欄位。
- 日期格式為 `中華民國114年6月16日` 或 `中華民國 114 年 6 月 16 日`。

範本文案類型：

- 縣長獎：姓名 + 畢業同學 + 品學兼優 + 榮獲學年度縣長獎。
- 家長會長獎國小：六 + 班級 + 姓名 + 同學 + 於本校六年求學期間五育成績優良。
- 家長會長獎幼兒園：班級 + 姓名 + 同學 + 於本校幼兒園求學期間成績優良。
- 教育基金會：班級 + 姓名 + 同學 + 在本校六年求學期間五育成績優良 + 董事長署名。

## 今年工具設計建議

今年工具不應只支援單一 CSV。建議支援兩種匯入：

1. 寬表模式：像去年的 `113畢業得獎名單.xlsx`，每欄一個獎項，欄內列姓名。
2. 明細表模式：一列一張獎狀，欄位為 `className`、`seatNo`、`studentName`、`awardName`、`section`、`templateId`。

建議資料模型：

| 欄位 | 說明 |
| --- | --- |
| `studentName` | 學生姓名 |
| `className` | 班級，例如六年忠班、幼兒園 |
| `seatNo` | 座號，可選 |
| `awardName` | 獎項名稱 |
| `templateId` | 使用哪一種獎狀模板 |
| `section` | 國小、幼兒園、資源班等 |
| `awardDate` | 頒獎日期 |
| `signerTitle` | 校長、家長會長、董事長等 |
| `signerName` | 署名，可選 |

今年工具需要新增的能力：

- 匯入 Excel `.xlsx`，不只 CSV。
- 自動把寬表轉成一列一張獎狀。
- 支援獎項模板管理，不同獎項可有不同文案與邊框。
- 支援國小/幼兒園不同文案。
- 預覽與列印時可依獎項篩選。
- 輸出前顯示缺漏資料檢查，例如只有姓名但缺班級。
